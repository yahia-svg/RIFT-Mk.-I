### August 30: Brainstorming Product Design and Searching for Inspiration<br />

The first thing I want to work on for this split keeb is to determine exact the design style I want to use. <br />
Right now, I'm gravitating towards some sort of mix between brutalism and futurism. <br />
So, I'm going to put all the designs that I find inspiring here. <br />
I'll also document my thoughts on each design highlighting what I like and what I don't like about each one, and I'll be using Pinterest as the main tool to find these designs.<br />
Afterwards, I'll probably finish the PCB before diving any deeper in the design, so I'd have a solid foundation to model over, hopefully leading to fewer design iterations. <br />
But let me stick to brainstorming the design right now, because I don't want to get too ahead of myself.<br />
My main inspiration for the design when I was imagining was batman's batmobile from the dark night so I'll start with that<br />

#### 1- The Tumbler from ``Batman Begins: The Dark Night`` 
<img width="1200" height="839" alt="image" src="https://github.com/user-attachments/assets/ca3b58be-f475-4d49-9ec0-ef716614d864" />
What I like:
<ul>
<li>It has so much depth due to the extreme amount of detail that was created by using so many panels</li>
<li>The design is very angular which gives it a really unique aggressive look</li>
</ul>
What I don't like: <br />
Even though the design is definitely very brutalist, which I like. I don't really find it very futuristic.<br />
I would've liked it more if it had more visible tech and more glass elements and maybe also some LEDs.

#### 2- Hard-surface modeling (image by [Stas Mikhailov](https://www.artstation.com/artwork/g8Dale))
<img width="1920" height="1122" alt="image" src="https://github.com/user-attachments/assets/9b39bf88-5340-4ecf-9b0f-3254edcc6f50" />
What I like:
<ul>
<li> Hard-surface details, like, indented surfaces; visible bolts and screws; and sharp edges, are so cool. They're certainly very futuristic and sci-fi-like</li>
<li> This design specifically uses long narrow LEDs, and I really like that because it makes them not very distracting and pretty sleek</li>
</ul>
What I don't like: <br />
It looks too clean and not brutalist enough because it uses way too many smooth edges

What I like:
<ul>
<li> It has some really nice Hard-surface details in the inner section like smooth curved edges, hard outlines, visible screws, and a random extruded&indented pieces for absolutely no reason lol</li>
<li> The exterior consists of multiple panels(and I love panels)</li>
<li> It uses a matte material for the blocky parts and a metallic material for the finer details. This is such a smart design choice, because it so elegantly blends 2 different design styles without making either one seem out of place </li>
</ul>
What I don't like: <br />

I wouldn't say I __don't like__ this, but I certainly would've prefered some lights because lights are just so cool and futuristic

#### Finally, the style I've decided on is...

Using large flat matte black overriding panels, for the main body of the keyboard in order to give it an aggressive silhouette and a brutalist look. I'll also mix it with some metallic parts for the areas with fine details such as the space right below the keycaps and maybe also other detailed areas that I'll add just for stylistic purposes. And the cherry on top would be the LEDs, I don't know where I'll add these just yet because I want them to also be functional and not just stylistic, but I will try to shape them into long narrow strips.
